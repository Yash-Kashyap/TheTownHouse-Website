# The Town House

Website for The Town House, an all-day cafe and kitchen near Delhi Gate in Nahan, Himachal Pradesh.

It's a small two-page site: a home page with hours, location, reviews and a tap-to-call button, and a menu page. Built to be fast, readable on a phone, and easy for Google to understand.

## Run it

The Astro project lives in `astro build of site/`.

```
cd "astro build of site"
npm install
npm run dev
```

`npm run build` writes the static site to `dist/`, and `npm run preview` serves it locally.

## Stack

Astro and Tailwind CSS. Deployed as static files on Netlify.
